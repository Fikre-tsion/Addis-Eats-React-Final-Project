# Addis Eats React Final Project

A modern Ethiopian restaurant ordering app built with React and Vite.

## Features

- Home landing page with hero section and featured dishes
- Menu browsing with category filtering
- Dish detail view
- Cart management with quantity updates and total calculation
- Login flow with protected checkout route
- Checkout form with validation and order confirmation
- Responsive, polished UI designed for restaurant ordering

## Tech Stack

- React
- Vite
- React Router DOM

## Getting Started

### Install dependencies

npm install

### Run the app in development mode

npm run dev

### Build for production

npm run build

## Project Structure

- `src/` — application source code
- `public/dishes.json` — menu data
- `src/auth/` — authentication context and login flow
- `src/cart/` — cart state and cart UI
- `src/checkout/` — checkout form and validation
- `src/menu/` — menu, home, and dish detail pages
- `src/ui/` — shared layout and error handling
